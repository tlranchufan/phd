Merge existing QuickSheets

Upload multiple QuickSheets to append them into one workbook. You can add them in several separate upload rounds. The merger normalises common header variants, forms the union of all columns, and leaves cells blank where a source workbook does not contain a column.

Add QuickSheets in one or more upload rounds, then click Merge QuickSheets.

How ratios and blanks are handled

If a processed workbook already contains a ratio summary, that summary is used. When K/Cs, Na/Cs or Rb/Cs is missing, the processed-workbook builder calculates the ratio for each valid inclusion and then calculates its average, sample standard deviation and RSD. Inclusion values that are blank, below detection, non-numeric, or have a zero Cs value are excluded.

The collated importer reads summary statistics from the first worksheet. It preserves available ratio columns, but leaves a missing ratio blank rather than estimating its standard deviation or RSD from summary averages.

All workbook processing happens locally in the browser. Uploaded data is not sent to the website.
